# ProofMatch AI — Career Experience / Module 1: AI Mock Interview

**Status:** Module 1 implemented and source-tested in this archive. The existing recruiter-facing Interview Companion at `/demo/interview` remains unchanged.

## Open the experience

- Career Experience hub: `/demo/career`
- AI Mock Interview: `/demo/career/interview`
- Available in the workspace sidebar and from the overview dashboard.

## End-to-end experience

1. Pick a target role (Frontend, QA, Data Analyst, Cybersecurity, UI/UX, Marketing, Project Manager), experience level, interview focus (balanced / technical / behavioral), interviewer style (supportive / focused / challenging) and question count (4 / 6 / 8).
2. Add optional background and project information, up to 1,600 characters, for live AI personalization; the on-device guided fallback uses only recognized career skills from the profile.
3. Enter the interview room with an animated Mira interviewer. Play each question using the browser speech-synthesis engine. Answer with text or browser speech transcription, where permitted. Optionally enable a private self-camera preview (no recording or upload).
4. Pause/resume, skip questions, see elapsed time and coaching time guides, and inspect previous feedback. A draft answer and the in-progress session are saved to browser localStorage.
5. Receive per-answer feedback on text relevance, specificity, and structure; review the practice report, detailed transcripts, next steps and export a `.txt` record. Delete saved interview histories when desired.

## Real AI connection and predictable fallback

When a valid `GEMINI_API_KEY` is configured on the server, `POST /api/career/interview` calls Gemini to generate response-aware follow-up questions and specific coaching feedback. Set `GEMINI_MODEL` to an accessible model for the account; defaults follow the project configuration. The key stays on the server.

Without an AI key, without model access, during quota limits, or on transient failure, the system continues the interview with a deterministic role-aware question bank and explicitly labeled **structured practice feedback**. It does NOT pretend this feedback was generated by Gemini. A user can finish the full experience without API credits. No external text-to-speech service is needed; native browser speech synthesis powers question playback.

A shared `DEMO_ACCESS_CODE`, if configured for the existing project, is also used by this API. For the mock interview, enter the access code under **Interview settings**; the UI does not expose the environment variable name to users. The client stores only this optional access code in sessionStorage; it is not included in exported interview reports.

## Privacy and intended use

This is an educational interview *practice* experience, not a verified candidate assessment or automatic hiring decision. Feedback measures coarse communication patterns in entered/transcribed answers, not personality, employability, factual truth or real-world ability. If Gemini is configured, submitted answers and optional background details are sent to the server and then to Gemini for coaching. The service does not persist responses server-side in this implementation. Browser localStorage holds practice history on the current device; this is not cross-device account synchronization and is unsuitable for sensitive personal data. Camera video stays in the browser and is never recorded/transmitted by this module. Browser speech recognition support and its voice-processing behavior vary by platform; check your browser's privacy policies before using it. Use fictional or consented practice data.

## Browser support

- Works for **typed interviews** on mainstream modern browsers.
- Microphone transcription uses `SpeechRecognition` / `webkitSpeechRecognition` where exposed by the browser; when unsupported or declined, the text field remains available.
- Question playback uses built-in Web Speech `speechSynthesis` where available.
- Camera preview requires a secure context (HTTPS or localhost), explicit permission and `getUserMedia` support; it is optional.
- Responsive layout includes reduced-motion support.
